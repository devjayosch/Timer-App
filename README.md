# Timer App

A simple timer app built with **HTML and JavaScript**.

The app allows you to start, pause and stop a countdown timer.

## Features

* Start the timer
* Pause the timer
* Stop and reset the timer
* Countdown from 60 seconds
* Updates every second

## Built With

* HTML
* JavaScript

## Getting Started

Clone the repository:

```bash
git clone https://github.com/devjayosch/Timer-App.git
```

Open the project folder and launch `index.html` in your browser.
